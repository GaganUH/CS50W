# CS50W Project 0 — Search

This project is part of Harvard University's **CS50's Web Programming with Python and JavaScript (CS50W)** course.

## Overview

Project 0 recreates the front-end functionality of Google Search using HTML and CSS.

The project includes three search pages:

- Google Search
- Google Image Search
- Google Advanced Search

## Features

- Standard Google Search
- Google Image Search
- Google Advanced Search with:
  - All these words
  - Exact word or phrase
  - Any of these words
  - None of these words
- "I'm Feeling Lucky" functionality
- Navigation between search pages
- Styling inspired by Google's interface

## Technologies Used

- HTML5
- CSS3
